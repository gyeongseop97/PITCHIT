# PITCHIT

5×5 존에서 투수와 타자가 동시에 선택하는 3이닝 야구 심리전 게임입니다.

## 플레이 모드

- **싱글 플레이**: AI를 상대로 타격·투구를 연습합니다.
- **빠른 대전**: 온라인 대기열에서 다른 플레이어와 자동 매칭합니다.
- **친구와 플레이**: 6자리 초대 코드로 상대를 초대합니다.

## 게임 규칙

- 타자는 **5×5** 타격판에서 노림 칸을 고릅니다. 컨택 스윙은 3×3, 파워 스윙은 인접 십자, 스팟 스윙은 한 칸을 공략합니다. 색깔 범위 안이라도 정확히 노린 칸을 맞힐수록 타구 질이 좋아집니다. 정확 적중 보상은 컨택 < 파워 < 스팟 순입니다. 세 스윙 모두 타겟 바로 주변 8칸에 공이 오면 헛스윙 대신 파울 확률이 크게 올라갑니다.
- 투수도 **5×5 스트라이크존**의 25개 코스를 고릅니다. 여기에 상·하·몸쪽·바깥쪽 4개 유인구 작전을 추가로 선택할 수 있습니다. 유인구는 타자가 그 방향을 읽었을 때만 헛스윙 위험이 생기며, 읽지 못하면 볼이 됩니다. 중앙 승부는 피안타 위험이 높고, 구석 승부는 피안타 위험은 낮지만 실투·볼 위험이 높습니다. 실투는 낮은 확률로 타자의 정확 타겟 또는 해당 스윙의 색깔 범위에 들어가는 위험한 공입니다.
- 투수의 구속·제구·구위·변화 능력치도 구속, 실제 투구 위치, 컨택 및 장타 확률에 반영됩니다.
- 매 턴 제한 시간은 20초이며, 시간이 지나면 자동 선택됩니다.
- 3회 말 종료 후 경기가 끝납니다.

## 온라인 대전 환경 변수

Vercel에서 아래 환경 변수를 설정합니다.

```text
KV_REST_API_URL=
KV_REST_API_TOKEN=
```

온라인 매치 API는 `app/api/match`에 있으며, Upstash Redis에 방과 대기열을 저장합니다. 빠른 대전은 짧은 Redis 잠금으로 대기열 등록·매칭을 직렬화하고, 친구 방의 입장·선택에도 방 단위 잠금을 사용합니다.

## 확률 검증

판정은 `lib/game-engine.ts`의 순수 함수로 분리되어 있습니다. 아래 명령으로 10만 타석 시뮬레이션을 실행할 수 있습니다.

```bash
npx tsx scripts/simulate-engine.ts
```

시뮬레이터는 무작위 추측·일반 심리전·높은 예측 성공률과 네 타자/투수 유형, 스윙별 정확 적중/주변 적중, 중앙/구석 투구를 각각 10만 타석씩 측정합니다. 최근 일반 심리전 가정(상대 선택 예측 35%)의 기준치는 타율 약 **.297**, 삼진율 약 **.181**, 홈런율 약 **.023**입니다. 기준 능력치에서 정확 적중 타율은 컨택 **.314**, 파워 **.364**, 스팟 **.418**이고, 주변 적중에서는 컨택 **.210**, 파워 **.304**입니다. 수치는 실제 스윙·유인구 선택 분포에 따라 달라집니다.

가운데 컨택 고정 전략도 별도로 검증합니다. 중앙 투구에는 타율 약 **.367**이지만, 구석 투구에는 타율 **.000**, 출루율 약 **.050**으로 막힙니다. 중앙 투구를 정확히 읽었을 때는 파워 **.419**, 스팟 **.471**로 컨택보다 높은 보상을 받습니다.

`scripts/inspect-pitch-risk.ts`는 투수·구종·위치별로 각각 10만 구를 던져 실투와 볼 위험을 측정합니다. 구속형 패스트볼은 중앙 실투율 약 **0.4%**, 변두리 **2.2%**, 모서리 **4.4%**와 모서리 볼 확률 **3.6%**입니다. 제구형 패스트볼은 중앙·변두리·모서리 모두 약 **0.5%**로 낮고, 변화구 모서리는 약 **0.5%**입니다. 변화형은 변화구 모서리 실투율 약 **2.8%**로 구속형 변화구 약 **6.2%**보다 안정적입니다.

## 배포

GitHub `main` 브랜치와 Vercel 프로덕션 배포를 함께 사용합니다. GitHub Pages에서 열어도 친구 대전과 빠른 대전은 Vercel의 `/api/match` 서버를 사용합니다.

## 아이템 상점

공 · 배경 · 효과를 각각 구매하고 카테고리별로 하나씩 장착합니다. 구매 후 장착 버튼으로 적용하며 다른 카테고리의 장착은 유지됩니다. 각 카테고리의 기본 아이템은 무료이고, 나이트·레트로·네온 구성품은 각각 70·90·110P입니다.

기존 `set-*` 구매 내역은 해당 공·배경·효과 세 개의 보유 내역으로 이전됩니다. 기존 코인·경기 보상 내역은 유지되며, 로그인 계정과 기기 저장 모두 동일한 규칙을 사용합니다.

상점 데이터와 구매·장착 규칙은 `lib/shop.ts`, 화면 템플릿은 `scripts/shop-ui.template`에서 수정합니다. `npm run sync:shop`으로 세 HTML 진입점에 반영하며 정적·서버 빌드에서도 자동 동기화합니다. `npm run verify:shop`은 이전·개별 구매·독립 장착·잔액·보유 검증과 모의 저장소를 사용하는 계정 API 검사를 실행합니다.

## 3D 그래픽 데모

정식 화면의 **3D 모드**를 켜고 방을 만들거나 친구·빠른 대전에 입장하면 `graphics3D` 설정이 전송됩니다. 서버는 두 참가자의 설정 중 하나라도 켜져 있으면 양쪽에 3D 시작을 알립니다. 기존 방·선택·경기 판정 방식은 같습니다. WebGL을 지원하지 않는 기기는 2D로 계속 플레이할 수 있습니다. `node scripts/verify-3d-rooms.mjs`에서 친구·빠른 대전의 네 가지 설정 조합을 검증합니다.

결과 해설·최근 투구 기록·위치 마커·점수 갱신·효과음은 배트 접촉 또는 포수 미트 도착 뒤에 표시합니다. 타자의 몸·골반은 타석 안쪽을 향하며, 경기마다 좌우 투타를 무작위로 배정합니다. 온라인에서는 방 코드로 양쪽의 좌우 투타를 일치시킵니다. 타격 후에는 배트를 내리고 1루로 달리며 장타는 다음 베이스로 이어집니다.

투구·타격 카메라는 공이 날아오는 동안 고정합니다. 타격 후 0.32초 동안 접촉을 보여 준 뒤 넓은 수비 시점으로 한 번 전환하고, 일정한 거리에서 공을 따라 이동합니다. 포구와 송구마다 확대·축소하지 않습니다. 작전 버튼은 연출 중에도 코스 선택으로 즉시 돌아갑니다. 구분 참고: [MLB The Show의 Pitching View / In-Play View 설정](https://playstation-doc.net/j/theshow15/ps4/option1.html).

홈과 경기 화면의 **3D 데모** 버튼은 현재 PITCHIT의 2D/3D 그래픽만 전환합니다. 기존 싱글·빠른 대전·친구 대전, 5×5 코스 선택, 스윙 유형·구종·유인구, 선택 제한 시간과 서버 판정은 그대로입니다. 별도 타이밍 스윙이나 연습 경기 엔진은 추가하지 않습니다.

`public/3d/scene.js`는 이미 확정된 실제 투구 위치·구종·구속·판정을 받아 투수·타자·포수와 공을 움직이는 표시 계층입니다. 홈과 마운드 기준점 간 거리는 18.44m입니다. 중계·타자·투수·측면 카메라를 선택할 수 있고, 현재 주자와 장착한 공·배경·효과도 표시합니다. 타구·포구 동작은 판정 결과를 설명하는 연출이며 추가 확률 계산이나 점수 변경을 하지 않습니다.

3D의 **작전** 시점에서는 타석 앞에 놓인 25개 면을 직접 클릭하거나 터치해 코스를 선택합니다. 방향키와 Enter도 지원합니다. `scripts/3d-entry.template`은 해당 입력을 원래 선택 버튼으로 전달하므로 선택 잠금·서버 요청·게임 판정은 그대로 유지됩니다. 2D로 전환하면 원래 선택판이 다시 나타납니다. `npm run sync:3d`와 정적/서버 빌드에서 자동 동기화합니다.

확정된 투구·타격 결과는 `public/3d/commentary.js`에서 한국어 해설로 표시합니다. 지원 브라우저에서는 **음성 해설**을 켤 수 있습니다. 타구가 발생하면 카메라가 공을 따라가고 연출 종료 후 작전 시점으로 돌아옵니다. 작전 버튼으로 즉시 복귀하거나 타구 추적을 끌 수 있으며, 동작 줄이기 설정에서는 추적이 기본으로 꺼집니다. 타구 궤적은 결과를 보여 주는 연출입니다.

`public/3d/defense.js`는 내·외야수 7명의 타구 추격 → 포구 → 송구 → 수신 동작을 담당합니다. 땅볼 아웃은 1루 송구, 안타·뜬공은 내야 반환 연출을 사용하며 홈런·파울에는 포구를 붙이지 않습니다. 수비 경로는 확정 판정을 설명하는 안무이며 실제 수비 시뮬레이션으로 추가 아웃을 만들지 않습니다. 타구 처리 중에는 수비수와 공을, 송구 때는 송구자와 수신자를 함께 담습니다.

작전 화면의 선택 칸은 금색, 기존 스윙 범위는 강도에 따라 청록·파랑·보라로 표시합니다. 실제 투구 위치는 분홍 십자 마커와 최근 6구 기록에 남아 다음 칸을 선택해도 유지됩니다. 행·열은 포수 시점 기준이며 존 밖 판정과 위치 정보가 없는 판정은 별도로 기록합니다. 새 경기를 시작하면 기록을 초기화합니다.

투구 시 다리 들기·디딤·릴리스·팔로스루를 연결하고, 타격은 두 팔이 배트 손잡이를 따라가는 스윙을 사용합니다. 작전 시점에서 진행하면 투구 폼과 타격을 보여 주는 카메라로 전환한 뒤 수비를 추적합니다. 구도 참고: [더쇼의 포수 뒤 타격 시점](https://www.operationsports.com/all-batter-and-pitcher-camera-settings-in-mlb-the-show-25/), [컴투스프로야구의 타격 화면](https://cpbv-community.com2us.com/board/all/147188). 외부 게임의 모델·이미지·모션 자산은 포함하지 않습니다.

검증: `node scripts/verify-3d-commentary.mjs`, `node scripts/verify-3d-browser.mjs` (Playwright 필요, `PLAYWRIGHT_MODULE` 및 `BROWSER_CHANNEL` 지정 가능). 브라우저 검증은 로컬 경기와 모의 서버 응답으로 25칸 입력·선택 잠금·기존 요청 형식·해설·카메라 추적을 확인합니다.

Three.js 0.180.0을 로컬에 포함하여 외부 CDN 없이 로드합니다. [Three.js 설치 문서](https://threejs.org/manual/en/installation.html), MIT 라이선스는 `public/3d/vendor/THREE-LICENSE.txt`를 참고하세요. WebGL 초기화 실패 시 기존 2D 화면으로 복구합니다.
