# PITCHIT

5×5 존에서 투수와 타자가 동시에 선택하는 3이닝 야구 심리전 게임입니다.

## 플레이 모드

- **싱글 플레이**: AI를 상대로 타격·투구를 연습합니다.
- **빠른 대전**: 온라인 대기열에서 다른 플레이어와 자동 매칭합니다.
- **친구와 플레이**: 6자리 초대 코드로 상대를 초대합니다.

## 게임 규칙

- 타자는 **5×5** 타격판에서 노림 칸을 고릅니다. 컨택 스윙은 3×3, 파워 스윙은 인접 십자, 스팟 스윙은 한 칸을 공략합니다. 색깔 범위 안이라도 정확히 노린 칸을 맞힐수록 타구 질이 좋아집니다. 정확 적중 보상은 컨택 < 파워 < 스팟 순입니다. 세 스윙 모두 타겟 바로 주변 8칸에 공이 오면 헛스윙 대신 파울 확률이 크게 올라갑니다.
- 투수도 **5×5 스트라이크존**의 25개 코스를 고릅니다. 여기에 상·하·몸쪽·바깥쪽 4개 유인구 작전을 추가로 선택할 수 있습니다. 유인구는 타자가 그 방향을 읽었을 때만 헛스윙 위험이 생기며, 읽지 못하면 볼이 됩니다. 중앙 승부는 피안타 위험이 높고, 구석 승부는 피안타 위험은 낮지만 실투·볼 위험이 높습니다.
- 투수의 구속·제구·구위·변화 능력치도 구속, 실제 투구 위치, 컨택 및 장타 확률에 반영됩니다.
- 매 턴 제한 시간은 20초이며, 시간이 지나면 자동 선택됩니다.
- 3회 말 종료 후 경기가 끝납니다.

## 온라인 대전 환경 변수

Vercel에서 아래 환경 변수를 설정합니다.

```text
KV_REST_API_URL=
KV_REST_API_TOKEN=
```

온라인 매치 API는 `app/api/match`에 있으며, Upstash Redis에 방과 대기열을 저장합니다. 빠른 대전은 짧은 Redis 잠금으로 대기열 등록·매칭을 직렬화하고, 친구 방의 입장·선택에도 방 단위 잠금을 사용합니다.

## 확률 검증

판정은 `lib/game-engine.ts`의 순수 함수로 분리되어 있습니다. 아래 명령으로 10만 타석 시뮬레이션을 실행할 수 있습니다.

```bash
npx tsx scripts/simulate-engine.ts
```

시뮬레이터는 무작위 추측·일반 심리전·높은 예측 성공률과 네 타자/투수 유형, 스윙별 정확 적중/주변 적중, 중앙/구석 투구를 각각 10만 타석씩 측정합니다. 최근 일반 심리전 가정(상대 선택 예측 35%)의 기준치는 타율 약 **.291**, 삼진율 약 **.201**, 홈런율 약 **.023**입니다. 기준 능력치에서 정확 적중 타율은 컨택 **.312**, 파워 **.368**, 스팟 **.418**이고, 주변 적중에서는 컨택 **.220**, 파워 **.313**입니다. 수치는 실제 스윙·유인구 선택 분포에 따라 달라집니다.

## 배포

GitHub `main` 브랜치와 Vercel 프로덕션 배포를 함께 사용합니다. GitHub Pages에서 열어도 친구 대전과 빠른 대전은 Vercel의 `/api/match` 서버를 사용합니다.
